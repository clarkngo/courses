This course applies the 4D AI Fluency Framework (Delegation, Description, Discernment, Diligence), created by Rick Dakan and Joseph Feller with Anthropic and released under [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/), to agentic coding with Claude Code. All lesson content, examples, and exercises are original to this course. Learn more about the framework at [aifluencyframework.org](https://aifluencyframework.org/).

Claude Code changes quickly. Feature names, commands, and modes described here reflect the product as of November 2026; check the [official Claude Code documentation](https://code.claude.com/docs) for the current details. The habits this course teaches matter more than any single feature, and they stay useful when the features change.
