One app, ten architectures. You start with a movie list and a search box running in a browser, then keep asking the same question: *what does this app need next, and what does adding it cost us in complexity and risk?*

Each module adds one tier — a phone, a backend and database, a CI/CD pipeline with a security scanner, rented cloud servers, a machine-learning recommender, experiment tracking, a local LLM, a vector database, and finally retrieval over your own documents. The focus is on concepts, vocabulary, and diagrams rather than step-by-step setup, with security trade-offs called out at every stage.
