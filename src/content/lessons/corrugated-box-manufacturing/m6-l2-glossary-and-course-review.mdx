## Glossary

| Term | Meaning |
|---|---|
| **BCT** | Box compression test — top-to-bottom strength of a box |
| **Blank** | The flat, cut, and scored piece before it's folded into a box |
| **BMC** | Box Maker's Certificate — the stamp stating board rating and limits |
| **Caliper** | Thickness of the board |
| **Double backer** | Corrugator section where the inside liner is glued and cured on hot plates |
| **ECT** | Edge crush test — edgewise compression strength of board, in lb/in |
| **FEFCO code** | International four-digit code for box styles (e.g., 0201) |
| **FFG** | Flexo folder-gluer — prints, slots, scores, folds, and glues boxes |
| **Flute** | One wave of the corrugated medium; sizes A, B, C, E, F |
| **Linerboard** | The flat facing papers of corrugated board |
| **Manufacturer's joint** | The glued, taped, or stitched seam that closes the box tube |
| **McKee formula** | BCT ≈ 5.87 × ECT × √(caliper × perimeter) |
| **Medium** | The fluted middle paper |
| **MSF** | Thousand square feet — the unit for pricing board |
| **Mullen** | Burst test, in psi |
| **OCC** | Old corrugated containers |
| **RSC** | Regular slotted container — FEFCO 0201 |
| **Single facer** | Corrugator section that forms flutes and glues the first liner |
| **Take-up factor** | Length of medium used per length of board |
| **Warp** | Board that isn't flat, usually from moisture imbalance |

<TryIt title="Capstone: Spec a Box">

A customer ships **24 cans** in a 4 × 6 arrangement. The pack measures **15.5 × 10.4 × 4.9 in** and weighs **22 lb**. Pallets are stacked **8 high**, stored up to **30 days** at about **70% RH**, and the customer wants to **interlock** for load stability.

Work through it:

1. **Style:** a low-cost shipper → RSC (0201). Might a tray + shrink film work instead?
2. **Inside dimensions:** add small clearance → about **15.75 × 10.625 × 5 in**.
3. **Required load on the bottom box:** 7 boxes above × 22 lb = **154 lb**.
4. **Derating:** 0.60 (30 days) × 0.80 (70% RH) × 0.55 (interlock) ≈ **0.264**.
5. **Needed lab BCT:** 154 ÷ 0.264 ≈ **585 lbf** (before any extra safety margin).
6. **Board:** try 32 ECT B flute, caliper ~0.12 in, perimeter 2 × (15.75 + 10.625) = 52.75 in.
   BCT ≈ 5.87 × 32 × √(0.12 × 52.75) ≈ 5.87 × 32 × 2.52 ≈ **473 lbf** — not enough.
7. **Options:** move to 44 ECT (≈ 650 lbf), **column-stack** instead of interlocking (factor rises to ~0.48, so 32 ECT would suffice), or let the cans carry part of the load.

Which option would you recommend, and why? There's more than one defensible answer — that's packaging engineering.

</TryIt>
