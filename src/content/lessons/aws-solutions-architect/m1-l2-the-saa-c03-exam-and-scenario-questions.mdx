## The Exam at a Glance

These details come from the official AWS exam guide, checked in November 2026:

| Item | Detail |
|---|---|
| **Exam code** | SAA-C03 |
| **Questions** | 65 total: **50 scored** and **15 unscored** (you can't tell which are which) |
| **Time** | 130 minutes |
| **Passing score** | **720** on a scale of 100–1,000 |
| **Question types** | Multiple choice (one correct answer out of four) and multiple response (two or more correct out of five or more) |
| **Cost** | 150 USD |
| **Delivery** | Pearson VUE test center or online proctored |
| **Valid for** | 3 years |
| **Recommended experience** | At least 1 year designing cloud solutions on AWS |

Scoring is **compensatory**: you need to pass the exam overall, not each domain. Unanswered questions count as wrong and there is **no penalty for guessing**, so never leave one blank.

<Pitfall title="Trusting a Third-Party Summary">

**Common mistake:** relying on a blog post or forum thread for exam facts. Some still say "40 scored questions" or list old service names.

AWS revises the exam guide (most recently in October 2026) and announces new exam versions ahead of time. Before you book, read the **current official exam guide**, including its in-scope and out-of-scope service lists.

</Pitfall>

## Anatomy of a Scenario Question

Most questions are a short story that ends with a requirement and a **qualifier**:

> A company runs a web application on EC2 instances behind an Application Load Balancer. Users upload images that are processed by the same instances, and processing sometimes takes minutes, which slows the website. The company wants to **decouple** image processing from the web tier **with the least operational overhead**. What should a solutions architect do?

The qualifier at the end decides between answers that would all technically work:

| Qualifier | What it usually rewards |
|---|---|
| **Least operational overhead** | Managed or serverless services; no servers to patch; built-in features over custom code |
| **Most cost-effective** | The cheapest option that still meets **every** stated requirement |
| **Most secure** / **least privilege** | Roles over keys, private connectivity, encryption with KMS, narrow permissions |
| **Highest availability** | Multi-AZ by default; multi-Region only if the question says Regional failure matters |
| **Lowest latency** / **best performance** | Caching, edge services, the right storage or instance type |
| **Minimal changes** to the application | Drop-in managed versions (RDS for MySQL, EFS for NFS, FSx for Windows) |

For the example above: SQS with a separate group of workers, or SQS triggering Lambda, both decouple the tiers. "Least operational overhead" tips it toward the managed and serverless option, as long as each job fits in Lambda's 15-minute limit.

Distractors are usually wrong for one of these reasons:

- **Wrong service for the job** (for example, using Kinesis where the question only needs a queue)
- **Breaks a requirement** (a single-AZ answer when high availability is required)
- **Works, but more effort** than another option (custom scripts on EC2 vs a managed feature)
- **Not a real feature** (a setting or integration that doesn't exist)

## Key Takeaway

SAA-C03 has **65 questions in 130 minutes**, a passing score of **720**, and four domains weighted **30 / 26 / 24 / 20**. Most questions are scenarios where several answers work. The **qualifier** (least overhead, most cost-effective, most secure) decides which one is best, so find it first.

<TryIt title="Find the Qualifier">

Take any five SAA-C03 sample questions from the official **AWS Skill Builder** practice question set. For each one, before reading the answers:

1. Write the **requirement** in your own words.
2. Circle the **qualifier**.
3. Predict the kind of service that should win (managed, serverless, cached, Multi-AZ, cheapest storage class).

Then read the options and check your prediction. Track how often the qualifier alone would have led you to the right answer.

</TryIt>
