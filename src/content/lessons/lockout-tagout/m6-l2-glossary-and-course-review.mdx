## Glossary

| Term | Meaning |
|---|---|
| **Affected employee** | Operates or uses equipment being serviced, or works in the area |
| **Alternative measures** | Effective protection that allows minor servicing without LOTO |
| **Authorized employee** | Locks or tags out equipment to service it |
| **Double block and bleed** | Two closed valves with a vent between, for process line isolation |
| **Energy-isolating device** | Physical device that prevents energy transmission (disconnect, valve, block, blind) |
| **Full employee protection** | Tagout protection equivalent to lockout, using extra measures |
| **Group lockbox** | Box holding isolation keys, locked by every worker on a job |
| **Hasp** | Device that lets multiple locks be applied to one point |
| **Live-dead-live** | Test the tester, test the circuit, test the tester again |
| **Lockout device** | Lock that holds an isolating device in the safe position |
| **Minor servicing** | Routine, repetitive, integral tasks; exempt only with effective alternative measures |
| **Other employee** | Works where LOTO may occur; must not remove locks or restart |
| **Periodic inspection** | Annual check of each procedure by another authorized employee |
| **Primary authorized employee** | Coordinator responsible for a group lockout |
| **Stored (residual) energy** | Energy remaining after isolation: capacitors, springs, pressure, gravity |
| **Tagout device** | Warning tag; doesn't physically prevent operation |
| **Try-out** | Attempting to start the machine to verify isolation |
| **Zero energy state** | Every energy source isolated, stored energy released, and verified |

## Key Requirements at a Glance

| Topic | Requirement |
|---|---|
| Standard | OSHA 29 CFR 1910.147 |
| Program parts | Procedures, training, periodic inspections |
| Devices | Provided, singularly identified, durable, standardized, substantial, identifiable |
| Tag attachments | Non-reusable, self-locking, at least 50 lb unlocking strength |
| Sequence | Prepare, shut down, isolate, apply devices, stored energy, verify |
| Release | Inspect, account for people, notify, remove own lock |
| Absent worker's lock | Verify not at facility, reasonable contact efforts, inform before return |
| Periodic inspection | At least annually, by another authorized employee, certified |

<TryIt title="Capstone: Write a Machine-Specific Procedure">

Choose a machine with at least **three** energy sources. Write a one-page visual procedure with:

1. Machine name, location, and the tasks it covers
2. A table of each **energy source**, its **magnitude**, its **isolating device**, and its **location** (add a photo for each)
3. **Shutdown** steps
4. **Isolation and lock** steps for each device
5. **Stored energy** steps for each source
6. **Verification** steps (try-out, gauges, voltage test)
7. **Release** steps
8. Who wrote it, who validated it at the machine, and the date

Then have an authorized coworker perform it while you observe, and fix what you learn.
