## Glossary

| Term | Meaning |
|---|---|
| **ABS / DNV / LR** | Classification societies that set ship construction rules |
| **AH36 / DH36 / EH36** | Higher-strength ship steel grades with increasing toughness |
| **Baseline (BL)** | Height reference, usually bottom of keel |
| **Block** | Prefabricated hull module |
| **Bulkhead** | Wall dividing the hull; may be watertight |
| **Ceramic backing** | Removable root support for one-sided full-penetration welds |
| **Dogs and wedges** | Fitting aids to pull plates into alignment |
| **Fairing** | Making plates and members smooth and true |
| **FCAW / SAW / SMAW / GMAW / GTAW** | Flux-cored / submerged arc / stick / MIG / TIG |
| **Fire watch** | Trained person watching for fires during and after hot work |
| **Frame number** | Fore-and-aft station location |
| **Hogging / sagging** | Hull bending with the middle up / middle down |
| **Longitudinal** | Fore-and-aft stiffener |
| **Marine chemist** | Certified person who tests and certifies spaces for entry and hot work |
| **Molded line** | Theoretical reference surface for dimensions |
| **NDT (VT, MT, PT, UT, RT)** | Visual, magnetic particle, penetrant, ultrasonic, radiographic testing |
| **PQR / WPS / WPQ** | Procedure qualification record / welding procedure specification / welder qualification |
| **Preheat** | Heating base metal before welding to prevent cracking |
| **Strongback** | Stiff beam tacked across a joint to hold alignment |
| **Throat** | Shortest distance from root to weld face (≈ 0.707 × leg for fillets) |
| **Transition joint** | Explosion-bonded steel/aluminum strip for joining dissimilar metals |

<TryIt title="Capstone: Joint Package">

Pick one structural joint (for example, a stiffener-to-deck fillet weld, or a shell plate butt). Prepare a one-page package:

1. **Location:** frame number, distance off centerline, height above baseline
2. **Members and materials:** plate thickness, steel grade (e.g., AH36), stiffener size
3. **Welding symbol:** draw it, and explain side, size, length, and pitch
4. **Fit-up requirements:** gap, bevel, alignment tolerances
5. **Process and WPS:** process, filler, position, preheat
6. **Distortion plan:** sequence and technique
7. **Safety:** hot work testing, fire watch, ventilation, PPE
8. **Inspection:** VT plus any required NDT and acceptance criteria
